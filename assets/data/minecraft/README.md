# MC竞猜数据

`blocks.csv` 使用原版 **Java 版 26.3** 注册表，排除 141 个技术性方块及放置、状态变体后共 1145 个方块，包含 26.2 和 26.3 的新增内容。UTF-8、英文逗号分隔，恰好保留以下 12 列：

名称、方块标识、可再生性、挖掘工具、发光性、完整方块、可燃性、透明性、爆炸抗性、硬度、首次加入版本、创造模式物品栏分类。

## 方块属性口径

- 名称采用官方简体中文译名；墙挂等技术变体不单独作为答案。标识采用命名空间 ID，不采用数字编号。
- 可再生性：生存模式不借助作弊或漏洞、不依靠持续探索新地形，能否无限获得或反复形成此方块。技术方块和不可获取的方块不因此成为可再生物品；例如空气、火、耕地的“是”表示可以反复形成。状态限制仍按游戏规则处理。
- 挖掘工具：比较下界合金镐、斧、锹、锄、剑和剪刀的实际速度，列出最快的工具类别。此项不是掉落条件，精准采集和工具材质门槛另行判断。
- 发光性：任一状态能发光即为“是”，包括点亮后的灯、蜡烛和充能后的重生锚。
- 完整方块：台阶统一为“否”，不考虑两个台阶合并的双层状态；其他方块依据完整 1×1×1 碰撞形状，所有状态完整为“是”，部分状态完整为“仅特定状态”。不以外观、透光或红石导电性推断。
- 可燃性：依据原版火焰能否烧毁此方块。熔岩引火和熔炉燃料不属于此项。
- 透明性：采用当前 Java 版实际光照衰减与各方向光照遮挡形状。完全阻光为“不透明”，存在衰减或部分遮挡为“部分透明”，其余为“透明”；不同状态的分类不一致时为“部分透明”。排除含水状态中水造成的额外影响。玻璃透明、树叶部分透明、遮光玻璃不透明；发光方块不必透明。
- 爆炸抗性、硬度：读取正式客户端；硬度有多个状态值时逐项列出。硬度 -1 表示正常挖掘无法破坏。
- 首次加入版本：按实际方块形态的历史，合并更名而不将扁平化后的 ID 当成新内容。只保留大版本，如 1.14、1.21、26.3；1.0 前为 `pre-classic`。例如现在的石台阶为 1.14，原来的石台阶对应平滑石台阶；虞美人继承玫瑰的早期历史。
- 创造模式物品栏分类：使用普通原版功能集、无管理员权限的分类列表，不含搜索栏和快捷栏重复项。仅记录分类名称，同一对象存在于多个分类时以“；”分隔，不记录序号或行列位置；不存在独立入口时写“非创造物品”。

## 物品表

`items.csv` 包含 507 个物品，保留名称、物品标识、可再生性、堆叠数量、稀有度、主色调、获得方式、创造模式物品栏分类、首次加入版本，共 9 列。

竞猜名称最多 10 个字符；超出此限制的“Mojang徽标旗帜图案”不纳入答案表，发布工具同步排除此条目。

排除方块表中对应的方块物品。小麦是唯一的共用标识特例：`minecraft:wheat` 同时代表作物方块和收获的小麦物品，后者不是方块物品，因此保留，方块名称写为“小麦作物”。种子、胡萝卜等与作物方块标识不同，也保留。

- 堆叠数量和稀有度读取默认物品堆栈；不枚举附魔、药水效果等组件变体。
- 唱片附带原版曲目名称，旗帜图案和锻造模板附带原版图案或升级名称，避免同名答案。
- 主色调采用默认 GUI 贴图及默认染色，排除透明背景，中位切分为最多四簇，再按 alpha 加权统计，只保留面积占比至少 8% 的颜色，按占比排列，以 `#RRGGBB` 表示。盾牌使用原版模型的几何与 UV 进行 GUI 方向投影后取色，不统计纹理展开图的空白或隐藏面。动态贴图采用首帧/默认模型，此列不覆盖所有状态、染色与组件变化。
- 获取方式允许多项：合成、熔炼和酿造等加工、方块/生物掉落、容器/考古战利品、自然生成的展示物，以及交易、装桶、产蛋等其他机制。仅作弊或创造模式能够得到的物品标为“不可获得”，这里指普通生存模式。
- 可再生性区分原料与成品：钻石不可再生，但村民出售的钻石装备可再生；金属坐骑盔甲不能由金属锭反推为可再生。地图复制保留原地图，仅消耗可再生空地图，因此地图可再生；模板复制消耗钻石，因此不可再生。
- 首次加入版本暂采用默认开启的正式版本，排除下一大版本的实验预览资源；例如樱花木为 1.20、试炼内容为 1.21、收纳袋为 1.21。更名和 26.3 的旧地图 ID 拆分继承原来的内容历史。

## 来源与复现

物理属性、名称、工具速度、物品组件、创造栏和配方来自 Mojang 正式客户端，下载后核对官方 SHA-1。历史结合各大版本官方资源、[Wiki 公开离线档案](https://zenodo.org/records/6693745)的 Java 历史记录以及官方发布说明。旧档案用于历史和可再生机制，不用于覆盖当前客户端的物理参数。

提取和核对工具见 [tools/minecraft](../../../tools/minecraft/README.md)。来源索引保留在工具目录，生成的逐条推导及核对缓存保存在 `target/minecraft-audit/`。数据尚未接入竞猜玩法。

两份正式表均不含空值或待核对项。生成工作表后，发布脚本会检查列结构、注册表覆盖、重复名称和字段取值，再写入正式文件。

竞猜答案排除的技术方块由 `tools/minecraft/technical.py` 统一定义，包括引擎内部方块、墙挂形式、盆栽组合、插蜡烛的蛋糕、装有内容物的炼药锅，以及连接茎、藤蔓主体等内部生长形式；保留这些变体对应的原始方块、普通围墙，以及命令方块（含循环、连锁）、结构方块与拼图方块。物品主色调仍保留在资料表中，但当前竞猜不会将其作为属性。
